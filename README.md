
## Zero to Frontier

Canonical production URL: https://zero-to-frontier.vercel.app

Canonical repository: `rn-collins/zero-to-frontier`

Vercel project `zero-to-frontier` is active. The duplicate `z2f-live` project is superseded; its public hostname is retained only as a path-preserving client redirect to the canonical site. See `deployment-registry.json` for the machine-readable registry entry.

The site is a static, source-forward AI-literacy guide. It requires no account and stores optional reading progress only in the visitor's browser.
